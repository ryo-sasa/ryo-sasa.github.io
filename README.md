# HILTON ROULETTE

日本国内のヒルトン系列ホテルから、**地方 / ブランド / 運営元 / タイプ**で対象を絞り込み、
ルーレットで今夜の宿泊先を決めるサイトです。結果は **LINE** でそのまま共有できます。

公開 URL: `https://ryo-sasa.github.io/`

## ファイル構成

```
ryo-sasa.github.io/
├── index.html            … ページ本体
├── assets/
│   ├── roulette.css      … スタイル（ダークネイビー × シャンパンゴールド）
│   ├── data.js           … ホテルのマスターデータ
│   └── roulette.js       … ルーレット描画・抽選・共有
└── README.md
```

ビルド不要の素の HTML / CSS / JS です。`main` に push すればそのまま公開されます。

## 機能

| 機能 | 内容 |
| --- | --- |
| 絞り込み | 地方・ブランド・運営元・タイプ（シティ / リゾート）。複数選択可、未選択は「すべて」 |
| 件数表示 | 各チップに、他の条件を適用したうえでの該当件数を表示。0 件のチップは自動で無効化 |
| 開業予定 | トグルで 2026〜2030 年の開業予定ホテルも抽選対象に加えられる |
| 抽選 | `crypto.getRandomValues` で偏りなく当選を決め、その位置に止まるようホイールを回す |
| 除外 | 「これを除外して回す」で候補から外して再抽選（解除するまで保持） |
| 履歴 | 直近 12 件を保存 |
| 共有 | LINE / Web Share API / テキストコピー |
| 保存先 | 絞り込み条件・除外・履歴は `localStorage` |

### アクセシビリティ

- 結果は `aria-live` で読み上げ、ホイールの `aria-label` に対象件数を反映
- タップターゲット 44px 以上、`:focus-visible` にゴールドのフォーカスリング
- `prefers-reduced-motion` で回転演出を短縮、`forced-colors` に対応
- 効果音は既定でオフ（オプションで有効化）

## LINE への送信について

LINE の **URL スキーム**を使っています。サーバーもトークンも不要で、そのまま GitHub Pages で動きます。

```
https://line.me/R/share?text=<エンコードした本文>
```

「LINEで送る」を押すと LINE の共有画面が開き、送信先（トーク / グループ）は利用者が選びます。
スマートフォンでは LINE アプリ、PC ではブラウザ版 LINE が起動します。

送信される本文の例:

```
🥂 今夜の一泊は、ここに決まり。

ヒルトン沖縄瀬底リゾート
ブランド：ヒルトン（フルサービス）
エリア：九州・沖縄／沖縄県 国頭郡本部町
運営元：ヒルトン直営

地図 ▶ https://www.google.com/maps/search/?api=1&query=...

— HILTON ROULETTE
```

> **自動送信（bot からの push 配信）にしたい場合**
> LINE Messaging API の push はトークンを伴うためブラウザから直接は呼べません（CORS とトークン露出）。
> Google Apps Script などのプロキシを挟む構成が必要です。
> なお LINE Notify は 2025 年 3 月末で提供終了しています。

## データについて

`assets/data.js` に、開業済み **36 施設（9 ブランド）** と開業予定 10 施設を収録しています。

- **ブランド階層** … ヒルトン公式のポートフォリオ区分（ラグジュアリー / ライフスタイル / フルサービス / フォーカストサービス）
- **運営元** … ヒルトン直営 25 / フランチャイズ 9 / 非公表 2。公開情報にもとづく参考値です
- **タイプ** … シティ / リゾートの分類は本サイト独自のものです

ホテルの増減があった場合は `HOTELS` 配列に 1 行足すだけで、チップ・件数・ホイールすべてに反映されます。

```js
{ n: '正式名', s: 'ホイール表示用の短縮名', b: 'ブランドid', r: '地方id',
  p: '都道府県', c: '市区町村', t: 'city|resort', o: '運営元id' }
```
